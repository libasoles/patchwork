---
description: Start the Patchwork dev server and open the app
---

Start the development server for Patchwork:

1. Run `npm run dev` in the background
2. Wait for the server to be ready (listen on port 3000)
3. Open http://localhost:3000 in the browser to verify the app loads
4. Check http://localhost:3000/blocks to verify the glyph dictionary loads

Note: Node version is pinned to Node 22 LTS via `.nvmrc`. If `npm run dev` fails, check that the correct Node version is active.
